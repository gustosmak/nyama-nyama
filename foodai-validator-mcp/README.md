# FoodAI Validator MCP Server

Этот MCP-сервер предоставляет инструмент `validate_recommendation` для проверки безопасности блюд и защиты от Prompt Injection.

## Инструменты
- `validate_recommendation(name, price, user_budget)` — проверяет блюдо на соответствие бюджету и наличие вредоносных паттернов.
